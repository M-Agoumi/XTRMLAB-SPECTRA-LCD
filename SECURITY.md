# Security policy

## Supported versions

Only the latest release and the `beta-latest` pre-release receive fixes.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them
privately through
[GitHub's private vulnerability reporting](https://github.com/M-Agoumi/XTRMLAB-SPECTRA-LCD/security/advisories/new).

Include what you found, how to reproduce it, and the version affected.
You should get a reply within a week. Once a fix is released you'll be
credited in the advisory, unless you prefer not to be.

Things that are in scope include the local control API
(`control_server.py`), theme import (a theme file from someone else is
untrusted input), the installer, and the release/signing pipeline.
